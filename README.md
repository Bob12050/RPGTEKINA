## ゲームの内容

**完全ステージ制** — 拠点(ホーム)を中心にすべてメニューで進むスタイル。

- **エリア&クエスト(モンストのノマダン式)**: 「ぼうけんへ」→ エリア(大ステージ)を選ぶと、中に短いクエスト(小ステージ)が複数。順番にクリアして進み、エリア最後のクエストを倒すと次エリアが解放。
  - 草原 → 森 → 洞窟 → 火山 → まりゅうのねぐら の5エリア + クリア後の**しれんの ま**(神クラスがボス)。全6エリア・17クエスト。
  - 各クエストは 1〜2WAVE + ボスの短い連戦(シームレス増援・WAVE間にHP/MP小回復)。
- **スカウト**: 戦闘中に「スカウト」でモンスターを勧誘。仲間の攻撃力が高いほど、相手のHPが減っているほど成功しやすい。「モンスターのごちそう」で成功率アップ。
- **配合**: ホームの「はいごう」で Lv10以上の2体から新しいモンスターが誕生。
  - 生まれる種族は親の**系統の組み合わせ**で決まる(通常配合の最高ランクはA)
  - **特殊配合レシピ**(31種)でしか生まれない伝説モンスターが多数!
    - **配合限定モンスター**は野良に出ず、通常配合の抽選にも入らない完全レシピ専用。B→A→S の3段ツリーで、中間種がさらに上位の素材になる(例: バジリスク+ワイバーン→ヒュドラ、ヒュドラ+グランドラゴン→りゅうおうバハムート)
    - さらに**隠し究極(神クラス)モンスター**が4体。Sランク配合種どうしを組む最深層(例: バハムート+レヴィアタン→りゅうしんヴリトラ)
  - **同種配合ボーナス**: おなじ種族どうしを配合するとプラス値が多く乗り(+3)、ステータスボーナスも手厚くなる(厳選要素)
  - 親のとくぎを3つまで継承、プラス値でステータス強化
- **モンスター**: 8系統・70種(ランクF〜S)。うち18種は配合でしか手に入らない伝説・神モンスター。牧場に50体までストック可能。パーティは**4体**編成。
- **モンスター図鑑**: ホームの「ずかん」から。出会った種族はシルエット、仲間にした種族はとくぎ・耐性まで全公開。配合限定種には**逆引きレシピ**(どの親から生まれるか)も表示され、未発見の親は`？？？`でマスクされる。コンプリートを目指せ!
- **目標**: ステージを進めて最奥のボス「まりゅうテキーナ」を倒せ! クリア後は しれんステージで神クラスに挑戦。
- **セーブ**: ホームの「セーブ」でいつでも保存(ブラウザの localStorage)。かいふくは拠点で無料。

## アーキテクチャ(拡張ガイド)

データ駆動設計なので、**データファイルに足すだけ**でコンテンツを増やせます。
`npm run test` がID参照や整合性を自動チェックします。

```
src/
├── core/        # 型定義・入力・シーン管理・乱数
│   └── types.ts       # ゲーム全体の型(まずここを見る)
├── data/        # ★ ゲームコンテンツ(ここを編集して拡張)
│   ├── monsters.ts    # モンスター図鑑(70種)→ 新種族はここに追加
│   ├── skills.ts      # とくぎ(32種)
│   ├── items.ts       # アイテム & ショップ品揃え
│   ├── synthesis.ts   # 配合の系統表 & 特殊レシピ(逆引きも)
│   ├── stages.ts      # ★ ステージ(連戦+ボス・解放条件・報酬)
│   └── maps.ts        # (旧)エンカウント表 ※現在はテスト用データ
├── game/        # 純ロジック(UI非依存・テスト対象)
│   ├── monster.ts     # 個体生成・ステータス計算・レベルアップ
│   ├── battle.ts      # バトルエンジン(イベント列を生成)
│   ├── scout.ts       # スカウト成功率
│   ├── synthesis.ts   # 配合ロジック(同種ボーナス・相性判定)
│   ├── save.ts        # セーブ/ロード(バージョン付き・移行処理)
│   └── state.ts       # ゲーム状態の操作(ステージクリア記録など)
├── scenes/      # 画面
│   ├── title / help                      # タイトル・あそびかた
│   ├── home                              # 拠点ハブ(全メニューの起点)
│   ├── stageSelect / stage / battle      # ステージ選択・連戦進行・戦闘
│   ├── synthesis / farm / shop / dex     # 配合・牧場・ショップ・図鑑
│   └── status                            # ステータス詳細
└── ui/          # 描画部品(DQ風ウィンドウ・ドット絵スプライト・タッチ操作)
tests/           # vitest(データ整合性・戦闘・配合・スカウト・セーブ・ステージ)
```

### 拡張の例

- **新モンスター**: `data/monsters.ts` に `species({...})` を1つ追加 → 図鑑・配合・戦闘すべてに自動反映
- **新ステージ**: `data/stages.ts` に `stage({...})` を1つ追加(waves + boss + requires) → セレクトに自動で並ぶ
- **新とくぎ**: `data/skills.ts` に追加して、モンスターの `learnset` から参照
- **新レシピ**: `data/synthesis.ts` の `SPECIAL_RECIPES` に1行追加(図鑑の逆引きにも自動反映)
- **セーブ互換**: 保存形式を変えるときは `SAVE_VERSION` を上げて `save.ts` の `migrate()` に変換処理を書く
