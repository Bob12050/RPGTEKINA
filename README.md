## ゲームの内容

- **フィールド探索**: 村 → 草原 → 森 → 洞窟 → 火山。歩くとモンスターが出現!
- **スカウト**: 戦闘中に「スカウト」でモンスターを勧誘。仲間の攻撃力が高いほど、相手のHPが減っているほど成功しやすい。「モンスターのごちそう」で成功率アップ。
- **配合**: 村の配合じいさんに Lv10以上の2体を預けると新しいモンスターが誕生。
  - 生まれる種族は親の**系統の組み合わせ**で決まる(通常配合の最高ランクはA)
  - **特殊配合レシピ**(27種)でしか生まれない伝説モンスターが多数!
    - **配合限定モンスター**は野良に出ず、通常配合の抽選にも入らない完全レシピ専用。B→A→S の3段ツリーで、中間種がさらに上位の素材になる(例: バジリスク+ワイバーン→ヒュドラ、ヒュドラ+グランドラゴン→りゅうおうバハムート)
  - 親のとくぎを3つまで継承、プラス値でステータス強化
- **モンスター**: 8系統・66種(ランクF〜S)。うち14種は配合でしか手に入らない伝説モンスター。牧場に50体までストック可能。
- **モンスター図鑑**: メニューの「ずかん」から。出会った種族はシルエット、仲間にした種族はとくぎ・耐性まで全公開。コンプリートを目指せ!
- **目標**: 火山の奥に眠るボス「まりゅうテキーナ」を倒せ! クリア後は禁断の配合も…?
- **セーブ**: メニューからいつでも保存(ブラウザの localStorage)。

## アーキテクチャ(拡張ガイド)

データ駆動設計なので、**データファイルに足すだけ**でコンテンツを増やせます。
`npm run test` がID参照や整合性を自動チェックします。

```
src/
├── core/        # 型定義・入力・シーン管理・乱数
│   └── types.ts       # ゲーム全体の型(まずここを見る)
├── data/        # ★ ゲームコンテンツ(ここを編集して拡張)
│   ├── monsters.ts    # モンスター図鑑(52種)→ 新種族はここに追加
│   ├── skills.ts      # とくぎ(32種)
│   ├── items.ts       # アイテム & ショップ品揃え
│   ├── synthesis.ts   # 配合の系統表 & 特殊レシピ
│   └── maps.ts        # マップ・エンカウントテーブル・NPC
├── game/        # 純ロジック(UI非依存・テスト対象)
│   ├── monster.ts     # 個体生成・ステータス計算・レベルアップ
│   ├── battle.ts      # バトルエンジン(イベント列を生成)
│   ├── scout.ts       # スカウト成功率
│   ├── synthesis.ts   # 配合ロジック
│   ├── save.ts        # セーブ/ロード(バージョン付き)
│   └── state.ts       # ゲーム状態の操作
├── scenes/      # 画面(タイトル・フィールド・バトル・配合・牧場・ショップ…)
└── ui/          # 描画部品(DQ風ウィンドウ・ドット絵スプライト)
tests/           # vitest(データ整合性・戦闘・配合・スカウト・セーブ)
```

### 拡張の例

- **新モンスター**: `data/monsters.ts` に `species({...})` を1つ追加 → 図鑑・配合・戦闘すべてに自動反映
- **新とくぎ**: `data/skills.ts` に追加して、モンスターの `learnset` から参照
- **新マップ**: `data/maps.ts` にビルダーで作成し、既存マップと `portals` でつなぐ
- **新レシピ**: `data/synthesis.ts` の `SPECIAL_RECIPES` に1行追加
- **セーブ互換**: 保存形式を変えるときは `SAVE_VERSION` を上げて `save.ts` の `migrate()` に変換処理を書く
