## ゲームの内容

**完全ステージ制のソシャゲ風RPG** — 拠点(ホーム)を中心にすべてタップで進むスタイル。
ホームは「上部に通貨バー / 中央にパーティ / 下部にアイコンボタン」のソシャゲレイアウト。バトルも下部の大きなコマンドボタンと敵への直接タップで操作。

- **エリア&クエスト(モンストのノマダン式)**: 「ぼうけんへ」→ エリア(大ステージ)を選ぶと、中に小さなクエスト(小ステージ)が複数。順番にクリアして進み、エリア最後のクエストを倒すと次エリアが解放。
  - 草原 → 森 → 洞窟 → 火山 → まりゅうのねぐら の5エリア + クリア後の**しれんの ま**(神クラスがボス)。全6エリア・17クエスト。
  - **1クエスト = 1回の戦闘**(敵は固定編成)。エリアの**最後のクエストは👑ボス戦**(強演出・逃走不可)。
  - エリア選択は**島マップ風**: ジグザグの道にエリアノードが並び、未開放はシルエット+🔒。
- **ガチャ**: モンスターの入手はガチャで! クエストの**初回クリアでオーブ**がもらえる。
  - 単発 5オーブ / **10連 45オーブ**(おトク & **★4以上1体確定**)
  - レア度はランク連動の **★2〜★7**。排出率は ★2 30% / ★3 35% / ★4 20% / ★5 10% / ★6 4% / ★7 1%
  - ★6・★7には伝説・神クラス(バハムート、セラフ、オーディン…)がずらり。高レアほど高レベルで加入する即戦力
  - はじめから遊ぶと**オーブ50個**持っているので、まず10連を回してパーティを組もう
- **周回ドロップ**: クリアするたびにアイテムドロップ+**モンスタードロップ**(倒したボス級が確率でついてくる)を抽選。2回目以降も**周回ボーナス**ゴールドがもらえる。
  - ガチャに出ない**★1モンスター(ぷに等)は序盤クエストのドロップ限定**。図鑑コンプにはクエスト周回も必要!
- **モンスター**: 8系統・70種(★1〜★7)。牧場に50体までストック可能。パーティは**4体**編成。
- **モンスター図鑑**: ホームの「ずかん」から。出会った種族はシルエット、仲間にした種族はとくぎ・耐性まで全公開。**入手方法のヒント**(ガチャ/クエストドロップ)も表示。コンプリートを目指せ!
- **目標**: クエストを進めて最奥のボス「まりゅうテキーナ」を倒せ! クリア後は しれんクエストで神クラスに挑戦。
- **セーブ**: ホームの「セーブ」でいつでも保存(ブラウザの localStorage)。かいふくは拠点で無料。旧バージョンのセーブは自動移行され、おわびオーブがもらえる。

## アーキテクチャ(拡張ガイド)

データ駆動設計なので、**データファイルに足すだけ**でコンテンツを増やせます。
`npm run test` がID参照や整合性を自動チェックします。

```
src/
├── core/        # 型定義・入力・シーン管理・乱数
│   └── types.ts       # ゲーム全体の型(まずここを見る)
├── data/        # ★ ゲームコンテンツ(ここを編集して拡張)
│   ├── monsters.ts    # モンスター図鑑(70種)→ 新種族はここに追加
│   ├── skills.ts      # とくぎ(32種)
│   ├── items.ts       # アイテム & ショップ品揃え
│   ├── gacha.ts       # ★ ガチャ(排出率・プール・確定枠)
│   └── stages.ts      # ★ ステージ(敵編成・ボス指定・解放条件・報酬オーブ)
├── game/        # 純ロジック(UI非依存・テスト対象)
│   ├── monster.ts     # 個体生成・ステータス計算・レベルアップ
│   ├── battle.ts      # バトルエンジン(イベント列を生成)
│   ├── save.ts        # セーブ/ロード(バージョン付き・移行処理)
│   └── state.ts       # ゲーム状態の操作(ステージクリア記録など)
├── scenes/      # 画面
│   ├── title / help                      # タイトル・あそびかた
│   ├── home                              # 拠点ハブ(全メニューの起点)
│   ├── stageSelect / stage / battle      # ステージ選択・連戦進行・戦闘
│   ├── gacha / farm / shop / dex         # ガチャ・牧場・ショップ・図鑑
│   └── status                            # ステータス詳細
└── ui/          # 描画部品(DQ風ウィンドウ・ドット絵スプライト・タッチ操作)
tests/           # vitest(データ整合性・戦闘・ガチャ・セーブ・ステージ)
```

### 拡張の例

- **新モンスター**: `data/monsters.ts` に `species({...})` を1つ追加 → 図鑑・ガチャ・戦闘すべてに自動反映
- **新ステージ**: `data/stages.ts` に `q({...})` を1つ追加(enemies + rewardOrbs、ボスなら boss: true) → セレクトに自動で並ぶ
- **新とくぎ**: `data/skills.ts` に追加して、モンスターの `learnset` から参照
- **ガチャ調整**: `data/gacha.ts` の `RANK_RATES` / `SINGLE_COST` などを変更(テストが合計100%を検証)
- **セーブ互換**: 保存形式を変えるときは `SAVE_VERSION` を上げて `save.ts` の `migrate()` に変換処理を書く
